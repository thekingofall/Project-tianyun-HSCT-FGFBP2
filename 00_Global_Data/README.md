# Data

`Shared_Inputs/Primary` contains the small inputs exported from the verified PBMC, T cell and fitted trajectory objects, plus existing statistics and STARTRAC inputs. The GSE-prefixed folders contain revision plotting tables, markers and annotations. Each panel links to its canonical input folder.

Large original inputs remain on server 252. See [external dependencies](../00_Settings/00_External_Data_Dependencies.tsv) for exact filenames, sizes and public cohort accessions. No raw FASTQ files or full expression objects are included in Git.

The external public cohorts are GSE223844 (salvage immunotherapy), GSE216187 (post-transplant bone marrow) and GSE222633 (longitudinal peripheral blood).
